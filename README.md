# Giftica bot 💛

Бот для магазина **Giftica** на Prom.ua. После каждого нового заказа он автоматически пишет покупателю благодарность в чат Prom.

## Как работает

- GitHub Actions запускает `bot.py` примерно каждые 5 минут.
- Бот берёт новые заказы через API Prom и отправляет сообщение в чат по этому заказу. Это то же самое, что написать покупателю вручную со страницы заказа.
- Отменённые заказы бот пропускает. Каждому заказу пишет только один раз: номера уже обработанных заказов хранятся в `done_ids.json`.
- При первом запуске бот только запоминает уже существующие заказы и никому не пишет.

## Настройка

1. В репозитории откройте **Settings → Secrets and variables → Actions** и добавьте секрет `PROM_TOKEN` с токеном Prom (доступ к заказам и чату).
2. Откройте **Actions → Giftica auto-message → Run workflow**, чтобы сделать первый запуск.

## Как изменить текст сообщения

Отредактируйте переменную `MESSAGE` в файле `bot.py`.

## Как выключить

Откройте **Actions → Giftica auto-message → ⋯ → Disable workflow**.

## Важно

- Токен хранится только в секретах GitHub, в коде его нет.
- На бесплатном GitHub запуск по расписанию иногда задерживается, и сообщение может прийти через 10–20 минут после заказа.
